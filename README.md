# Reveille Brew Co. (Squad 45)

Texas A&M-themed bubble tea POS web app for CSCE 331 Project 3.

## Structure
- `client/` – React frontend (Portal Hub, Manager, Cashier, Kiosk, Kitchen Display)
- `server/` – Node/Express API backed by PostgreSQL on the TAMU AWS server

## Setup
1. Copy `server/.env.example` to `server/.env` and fill in the DB credentials.
2. Install and run each of `server/` and `client/` (instructions to follow as they are scaffolded).
